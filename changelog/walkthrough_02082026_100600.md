# Walkthrough - Sửa lỗi Device Info / Push Token gửi dạng Promise

## Mô tả lỗi
Khi gửi token và thông tin thiết bị lên backend qua API `/post_data/expo_push_token_register/`, thông số `device_info` được lưu dưới dạng:
```json
{
  "_A": null,
  "_x": 0,
  "_y": 0,
  "_z": null
}
```
Đây là định dạng JSON hóa của một đối tượng **Promise** ở trạng thái **Pending** (`_x: 0` là pending trong Hermes engine). Nguyên nhân là do hàm `get_device_info()` là một hàm `async` nhưng khi gọi lại thiếu từ khóa `await`.

## Thay đổi
- Sửa file [NotificationContext.tsx](file:///d:/django_apps/rest/fontendapp/src/context/NotificationContext.tsx#L185): thêm `await` trước `get_device_info()`.

```diff
-      const device_info = get_device_info();
+      const device_info = await get_device_info();
```

## Kết quả
- `device_info` sẽ được giải quyết (resolved) trước khi gửi lên API, giúp backend lưu trữ đúng thông tin JSON của thiết bị thay vì lưu object Promise.
